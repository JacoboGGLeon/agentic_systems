# CLI 2.1.3

```text
agentic-systems version
agentic-systems api
agentic-systems doctor
agentic-systems new /ruta/nueva/proyecto
```

version muestra la distribución. api enumera los 18 exports. doctor informa
dependencias instaladas sin leer claves ni realizar inferencia. new usa los
recursos del wheel instalado y rechaza destinos existentes. No publica paquetes.
Consulta el [scaffolder](SCAFFOLDER_213.md) y la [API](API_213.md).
