# Agentic Systems 2.1.8

- RunResult.evidence() is the primary execution export. to_dict() delegates to it, retaining compatibility, schema and redaction rules.
- New guides cover concepts, graphs, execution, results, independent evaluation, Context/Memory and integrations.
- Five executable evaluations demonstrate exact outputs, required Tool evidence, conditional routes, expected failures and episodic stopping, with rejecting controls.
- Active learning material and the bundled authoring skill target 2.1.8. The CLI can export that same skill as a standalone downloadable ZIP.
- No new scaffolder, provider behavior, durable storage, distributed session propagation or general feature parity is claimed.
