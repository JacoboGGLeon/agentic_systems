# Checkpoint 1.1.8 - Static System Inspection

Status: implemented and validated locally.

## Initial State

- `AgenticSystem.inspect()` returned a useful but partial dictionary.
- Registry and Agent validation existed.
- Composition provenance was present.
- Relationships, contracts, profiles, capabilities, limits, and degradation
  risks were not unified.
- Human and structured output contracts were not versioned.

## Decision

Extend the existing inspection entry point and dictionary report instead of
adding a parallel inspector. Reuse static declarations and prohibit execution.

## Changes

- Added public `InspectReport` with `to_dict()` and `human_text()`.
- Added `agentic_systems.inspect.v1`.
- Added entities, relationships, contracts, Providers, Frameworks,
  capabilities, conflicts, limits, degradation risks, and diagnostics.
- Preserved legacy summary, warnings, errors, and `raise_if_errors()`.
- Added ADR 0010 and normative static-inspection documentation.
- Added no-execution, serialization, stability, and diagnostic tests.

## Compatibility

- `AgenticSystem.inspect()` signature is unchanged.
- `InspectReport` remains a `dict`.
- Existing legacy keys and `raise_if_errors()` remain.
- New report sections and methods are additive.
- `PUBLIC_API` increases from 105 to 106.
- No Provider/Framework protocol or execution result schema changes.

## Invariants

```text
inspection executes zero models
inspection executes zero tools
inspection does not hydrate provider or framework clients
structured output survives JSON round-trip
human output has stable order
relationships describe declarations, not execution evidence
every normalized diagnostic has a concrete suggestion
errors preserve legacy raise_if_errors behavior
```

## Risks Pending

- Credential and endpoint availability remain runtime concerns.
- User metadata that is not JSON-like may still require stronger registration
  validation before it reaches inspection.
- External Framework-native graph internals are not traversed; only declared
  boundary profiles are inspected.
- Dynamic Tool side effects cannot be inferred statically.
