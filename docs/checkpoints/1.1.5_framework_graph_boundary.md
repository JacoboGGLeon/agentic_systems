# Checkpoint 1.1.5 - Framework and Graph Boundary

Status: implemented and validated locally.

## Initial State

- Documentation called three framework identities facades even though only
  LangGraph had adapter code.
- Provider identities could leak into the Framework metadata field.
- `Agent.as_node` described a core state adapter as LangGraph-specific.
- Portable Environment Graphs and framework-native LangGraph wrappers had no
  common inspectable distinction.
- Graph projections could retain RunResult, but preservation was not tested as
  a shared contract.

## Decision

Keep central semantics in Agentic Systems, keep framework lifecycle and native
objects external, classify integration maturity explicitly, and require an
explicit `result_key` when a Graph state must retain the full RunResult
contract.

## Changes

- Added immutable Framework profiles and Graph-boundary descriptors.
- Added structured Framework projection conformance reports.
- Classified LangGraph as a real adapter, OpenAI Agents-style as style-only,
  and Strands as declarative-only.
- Added requested-versus-executed Framework metadata.
- Removed Provider names from Framework defaults in OpenAI/vLLM paths.
- Marked portable and framework-native Graph wrappers explicitly.
- Added `result_key` to framework-neutral Agent state-node adapters.
- Corrected public documentation that implied unavailable SDK integrations.
- Added ADR 0007 and a dedicated preservation suite.

## Compatibility

- Existing framework strings and `framework` metadata remain accepted.
- Existing Agent, Graph, and Provider method signatures remain compatible.
- New metadata and boundary APIs are additive.
- LangGraph remains optional and is not imported by core construction.
- No Strands or OpenAI Agents SDK dependency is added.
- Native LangGraph objects remain accessible.

## Invariants

```text
Provider identity is never Framework identity
requested Framework is not proof of adapter execution
core Agent and RunResult semantics remain framework-independent
portable Graph and framework-native Graph are inspectably distinct
full Graph projection preserves central RunResult fields
optional Framework imports stay outside core construction
```

## Risks Pending

- OpenAI Agents SDK and Strands remain unimplemented external adapters.
- Framework-native lifecycle, persistence, streaming, and concurrency are not
  normalized by the central API.
- `graph(...)` remains a compatibility name for the LangGraph facade and can be
  confused with portable Graph builders without reading its profile/docs.
- Framework substitution requires stronger lifecycle semantics than this
  projection-preservation checkpoint provides.
