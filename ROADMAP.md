# Roadmap · Agentic Systems 2.1.9

## 2.1.9: core grammar and first-run teaching

Teach Tools, Skills, model-backed agent actors, graph-based agent actuators, Graph and System composition, Context, Memory, Environment, Eval and RunResult evidence through progressive examples. Align installation, current references, notebooks and the bundled authoring Skill to the same version.

The candidate must pass exact-artifact checks before publication. Historical 2.1.8 Native and OpenAI Agents Bedrock results remain baseline evidence; they do not certify 2.1.9. This roadmap does not assert that 2.1.9 has been published.

## 2.1.10: explicit actor behavior controls

Develop and validate Agent contracts and policies, including `any_of` completion and interactions with Tool/turn limits, across the relevant provider/framework matrix. Existing API objects stay available; this is a validation and development scope, not removal from 2.1.9.

## Evidence boundaries

Memory and continuations remain process-local. No durable recovery, EMR or distributed Spark compatibility is implied. New claims require their own evidence tied to the exact artifact.
