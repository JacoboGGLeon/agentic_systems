# Examples · Agentic Systems 2.1.5

Examples use the public toolkit API and LangGraph orchestration. Begin with the [complete API walkthrough](api_walkthrough/01_api_user_guide.md), then [common graph patterns](common_graph/01_common_graph.md), [typed composition](checked_composition/01_checked_composition.md) and [Context/Memory](context_memory_lineage/01_context_memory_lineage.md).

[Lineage and Memory decisions](lineage_memory/01_lineage_memory_decisions.md) demonstrates causal evidence, duplicate review, Environment episodes and isolated Eval. [Financial composition](financial_mixed/01_financial_system.md) shows the same business contract in Python and a multi-provider live profile. No real funds are transferred.

[Borrowed AWS sessions](aws_session/01_aws_session.md) and the separate ADA package provide configuration diagnostics without resolving credentials; they do not certify IAM access. [Studio](agentic_systems_studio/README.md) is a separate application, not included in the SDK wheel.

Use the [English notebook index](../docs/NOTEBOOKS.md) for every notebook, its executable source and a Markdown fallback when GitHub previews fail. [The catalog](catalog.json) retains experiment identities and validation provenance. Historical live results do not certify current source or a newly built wheel. Local MCP/A2A and GPU serving have separate infrastructure requirements.

The applications and patterns directories retain the executable reference programs. Run offline examples with the repository validation scripts; configure and authorize live providers separately. No automatic provider fallback is allowed.
